# Платформа для поиска работы

## Описание задания

Разработать программное обеспечение для поиска работы с двумя функциями - управление вакансиями и управление резюме с отменой/повтором изменений. Программа должна иметь удобный консольный интерфейс и уметь хранить данные в структурированных текстовых файлах. Необходимо применить архитектуру MVC, а также два паттерна проектирования - один порождающий (Factory Method) и один поведенческий (Command) - при разработке программы. В качестве базы данных для хранения данных о вакансиях и резюме должны использоваться структурированные текстовые файлы.

## Описание работы с GIT

Ветка main изначально содержит Readme.md с описанием постановки задачи и файл .gitignore для сохранения только полезных данных. Все мерджи обязательно проходят ревью через пулл-реквест. Правила нейминга выбраны следующим образом:

main - ветка для хранения стабильного кода. Мердж через пулл-реквест и код-ревью.

feature - ветки для хранения кода бизнес-задачи. Мердж через пулл-реквест и код-ревью.

В случае нарушения нейминга пулл-реквест отклоняется без ревью кода.

## Пример

Ответственный за код-ревью: Гинжул Мария.

**Бизнес-задача №1. Управление вакансиями (Factory Method)**

Пользователи должны иметь возможность создавать, просматривать и удалять вакансии. Вакансии бывают разных типов: IT, Marketing, Sales. Для создания вакансий используется паттерн Factory Method, который создаёт нужный тип вакансии на основе пользовательского ввода.

Ответственный: Гинжул Мария. Ветвь бизнес-задачи: feature_vacancy-management.

**Бизнес-задача №2. Управление резюме с отменой/повтором (Command)**

Пользователи должны иметь возможность создавать и редактировать резюме (имя, опыт, навыки, желаемая зарплата). Для реализации отмены и повтора действий используется паттерн Command, который позволяет отменить (Undo) или повторить (Redo) последнее изменение резюме.

Ответственный: Сайбуу Вилена. Ветвь бизнес-задачи: feature_resume-management.
